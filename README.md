# FamilyBudget

FamilyBudget - консольное приложение для учёта расходов семейного бюджета. Проект предназначен для автоматизации добавления, редактирования и удаления расходов, управления категориями затрат и анализа финансов семьи.

**Автор:** Михеев Даниил, группа 26-ИВТ-4-2

## Возможности

В проекте предусмотрены следующие основные возможности:

- регистрация и авторизация пользователей;
- хранение информации о расходах семейного бюджета;
- добавление новых расходов;
- редактирование и удаление записей о расходах;
- распределение расходов по категориям;
- поиск и фильтрация расходов по различным параметрам;
- просмотр истории расходов;
- анализ расходов за выбранный период;
- формирование статистики и отчётов;
- хранение данных в базе данных SQLite.

## Предметная область

**Расход:** сумма, дата, категория, описание и пользователь, создавший запись.

**Категория:** название и описание категории расходов, например «Продукты», «Транспорт», «Коммунальные услуги» и «Развлечения».

**Пользователь:** идентификатор, логин и данные для авторизации в системе.

**Семья:** информация о семье и её участниках, если предусмотрен совместный учёт расходов.

Задача системы — упростить ведение семейного бюджета, обеспечить удобный контроль расходов и помочь пользователям анализировать распределение денежных средств.

## Пользователи и роли

| Роль | Возможности |
|---|---|
| Пользователь | Добавляет, редактирует и удаляет расходы, просматривает историю операций, использует фильтры и анализирует затраты |
| Администратор | Управляет пользователями и контролирует работу системы, если соответствующая роль предусмотрена |

## Структура базы данных

База данных `family_budget.db` создана с использованием SQLite. Она включает три таблицы: `Users`, `Categories` и `Expenses`.

### Таблица `Users`

Содержит информацию о зарегистрированных пользователях системы.

| Поле | Тип данных | Ограничения | Описание |
|---|---|---|---|
| `user_id` | INTEGER | PRIMARY KEY | Уникальный идентификатор пользователя |
| `username` | TEXT | UNIQUE | Имя пользователя для входа в систему |
| `password_hash` | TEXT | — | Хеш пароля пользователя |
| `full_name` | TEXT | — | Фамилия, имя и отчество пользователя |
| `family_role` | TEXT | — | Роль пользователя в семье |

### Таблица `Categories`

Содержит категории расходов семейного бюджета.

| Поле | Тип данных | Ограничения | Описание |
|---|---|---|---|
| `category_id` | INTEGER | PRIMARY KEY | Уникальный идентификатор категории |
| `category_name` | TEXT | — | Название категории |
| `description` | TEXT | — | Описание категории |

### Таблица `Expenses`

Содержит записи о расходах пользователей.

| Поле | Тип данных | Ограничения | Описание |
|---|---|---|---|
| `expense_id` | INTEGER | PRIMARY KEY | Уникальный идентификатор расхода |
| `user_id` | INTEGER | FOREIGN KEY | Идентификатор пользователя, добавившего запись |
| `category_id` | INTEGER | FOREIGN KEY | Идентификатор категории расхода |
| `full_name` | TEXT | — | ФИО человека, совершившего расход |
| `family_role` | TEXT | — | Семейная роль человека, совершившего расход |
| `amount` | REAL | CHECK (`amount > 0`) | Сумма расхода в рублях |
| `expense_date` | TEXT | — | Дата совершения расхода |
| `description` | TEXT | — | Описание расхода |

## Связи между таблицами

### Users — Expenses

В базе данных используются следующие связи:

- **Users — Expenses (один ко многим).** Один пользователь может добавить несколько записей о расходах, но каждая запись связана с одним пользователем.
- **Categories — Expenses (один ко многим).** Одна категория может использоваться во многих записях о расходах, но каждая запись относится к одной категории.

Связи реализованы с помощью внешних ключей `user_id` и `category_id`

## Обеспечение целостности данных

- **PRIMARY KEY (PK)** — обеспечивает уникальность каждой записи.
- **FOREIGN KEY (FK)** — связывает расходы с существующими пользователями и категориями.
- **UNIQUE** — предотвращает повторение логинов пользователей и названий категорий.
- **NOT NULL** — запрещает отсутствие значений в обязательных полях.
- **CHECK** — обеспечивает положительное значение суммы расхода.
